# speedtest.js

Простой **замерятель скорости скачивания** из интернета на чистом Node.js (без зависимостей).

Принимает URL файла (например, тяжёлой картинки), делает **10 последовательных
GET-запросов** к нему, дожидается полного ответа на каждый и выводит:

- среднее время запроса;
- суммарный объём скачанных данных;
- скорость скачивания в **МБ/с** и **Мбит/с**.

## Требования

- Node.js 14 или новее (используются только встроенные модули `http`/`https`). `npm install` не нужен.

## Использование

```bash
# По умолчанию: 10 запросов к статическому файлу 10 МБ
node speedtest.js

# Свой URL (любой тяжёлый файл / картинка), 10 запросов
node speedtest.js "https://example.com/big-image.jpg"

# Свой URL и своё число запросов
node speedtest.js "https://example.com/big-image.jpg" 20

# Справка
node speedtest.js --help
```

Аргументы:

| Позиция | Аргумент   | По умолчанию                            | Описание                        |
|---------|------------|-----------------------------------------|---------------------------------|
| 1       | `url`      | `https://proof.ovh.net/files/10Mb.dat`  | Файл для скачивания             |
| 2       | `requests` | `10`                                    | Число последовательных запросов |

> Цель по умолчанию — **статический** файл 10 МБ, чтобы результат отражал вашу
> сеть, а не время обработки на стороне сервера. Можно указать любую
> «тяжёлую картинку», например панораму ~14 МБ с Wikimedia:
> `https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg`
> (учтите: некоторые хостинги картинок ограничивают частые повторные запросы).

## Пример вывода

```
Target:   https://proof.ovh.net/files/10Mb.dat
Requests: 10 (sequential)

  Request 1/10 ... 6251 ms, 10.00 MB, 13.42 Mbit/s
  ...
  Request 10/10 ... 6362 ms, 10.00 MB, 13.19 Mbit/s

--- Results ---
Successful requests: 10/10
Average request time: 9178 ms
Total data downloaded: 100.00 MB
Speed: 1.09 MB/s  (9.14 Mbit/s)
```

## Как это работает

- Время каждого запроса меряется через `process.hrtime.bigint()` — от момента
  перед запросом до полного получения тела ответа.
- Скачанные байты считаются по чанкам потока ответа.
- Один уровень HTTP-редиректов отслеживается (типично для файлов на CDN).
- **Итоговая скорость** = суммарный объём скачанных данных ÷ суммарное время
  скачивания, выводится и в мегабайтах/с, и в мегабитах/с.
- Неуспешные запросы (таймауты, не-200 ответы, ограничение частоты) отмечаются и
  исключаются из средних; скрипт выдаёт результат, пока успешен хотя бы один запрос.

## Примечания

- `MB` здесь — **мебибайты** (1024 × 1024 байт); `Mbit/s` — десятичные мегабиты
  (÷ 1 000 000), как провайдеры обычно указывают скорость.
- Запросы выполняются строго **последовательно**, как и требуется, — следующий
  стартует только после завершения предыдущего.
